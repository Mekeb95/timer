# CrossFit Timer

En enkel og rask timer for CrossFit, HIIT og metcon-økter — bygget for mobil.

🔗 **[Åpne timeren](https://mekeb95.github.io/timer/)**

---

## Modi

- **For Time** – teller opp. Valgfri timecap som stopper økten automatisk.
- **AMRAP** – teller ned fra en valgt varighet.
- **EMOM** – veksler automatisk mellom work og rest over et valgt antall runder.

## Funksjoner

- 10-sekunders nedtelling før start
- Lyd og vibrasjon ved faseskift og slutt
- Visuell fremdriftslinje
- Rep-teller med 1 sekunds debounce
- Skjermen forblir på under aktiv økt
- Innstillinger lagres automatisk
- Fungerer som app på iPhone (legg til på hjemskjermen)
